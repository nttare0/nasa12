# NASA Explorer

A web application that explores NASA's amazing content using the NASA API.

## Features

- 🌌 Astronomy Picture of the Day (APOD)
- 🚀 Mars Rover Photos
- ☄️ Near Earth Objects (NEO) tracker

## Setup

1. Get a free API key from https://api.nasa.gov/
2. Open `index.html` in a browser
3. Enter your API key (or use the demo key)
4. Explore the universe!
